# MY_portfoliyo - Parth Mavani

Welcome to my personal student portfolio website. This application is built with React and Vite, featuring a modern design, modular component structure, and routing capabilities with React Router to showcase my background, statistics, and technical skills across multiple pages.

## Features
*   **Modular Component Architecture:** Structured using independent React components.
*   **Routing with React Router:** Multi-page application structure without page reloads featuring routes:
    * `/` - Home Page
    * `/projects` - Projects Page
    * `/contact` - Contact Page with a controlled form
*   **State Management:** Interactive elements using `useState` (e.g., dynamic light/dark mode toggle and contact form state).
*   **Modern Dark Theme:** Clean deep-space background palettes with high-contrast emerald/teal accents.
*   **High-Fidelity SVGs:** Integrated vector brand logos including Figma and PostgreSQL.
*   **Performance Optimized:** Configured on Vite for instant Hot Module Replacement (HMR).

## Getting Started

1. Clone the repository
2. Run `npm install`
3. Run `npm run dev`
